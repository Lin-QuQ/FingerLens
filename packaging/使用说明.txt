FingerLens 免安装版
===================

无需安装 Python 或 Anaconda。

Windows：
1. 完整解压 ZIP，不要直接在压缩包内运行。
2. 双击 FingerLens.exe。
3. 首次运行如果出现 Windows SmartScreen，请点击“更多信息”→“仍要运行”。
4. 在 Windows 设置中允许桌面应用访问摄像头。

macOS Apple 芯片（M1/M2/M3/M4/M5 及后续 Apple 芯片）：
1. 完整解压 ZIP。
2. 双击 FingerLens.app。
3. 如果系统提示无法验证开发者，请右键 FingerLens.app，选择“打开”，再确认一次。
4. 首次运行时允许 FingerLens 使用摄像头。

操作：
- 双手同时进入画面并张开手指。
- 两个手掌合到一起再分开，可切换下一套滤镜。
- 1–9：选择第 1–9 套滤镜。
- 0：选择第 10 套滤镜。
- B：开启或关闭磨皮（默认关闭）。
- H：显示或隐藏界面信息。
- M：切换镜像。
- 点击窗口右上角 ×、按 Q 或 Esc：退出。

常见问题：
- 摄像头无法打开：先确认 Windows 自带“相机”能正常显示，再开启“允许桌面应用访问摄像头”，检查摄像头物理开关和设备管理器驱动，并完全退出微信、腾讯会议、Teams、Zoom、OBS 等软件。
- 外接摄像头：免安装版会自动扫描 0、1、2 号摄像头；高级设置请参考源码仓库 README。
- 程序不会上传摄像头画面，所有处理均在本机完成。
